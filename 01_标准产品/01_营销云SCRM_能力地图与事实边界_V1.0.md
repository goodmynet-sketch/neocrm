## 1. 产品定位

销售易营销云中的 SCRM 能力，以企业微信生态为重要客户连接入口，将获客触点、客户关系、销售协同、客户运营与服务互动连接到 CRM 客户数据和业务流程中。内部资料将其概括为围绕客户全生命周期，覆盖“吸引获客—转化客户—服务客户”的运营过程。

**建议对外口径：**“SCRM 将企业微信客户连接与 CRM 客户经营结合，帮助企业把多渠道获客、客户互动、线索转化、私域运营和服务协同沉淀到统一客户数据与业务流程中。”

## 3. 按客户旅程拆解

### 3.1 吸引获客

- 多渠道引流：官网、公众号、小程序、视频号、广告投放、直播、展会和门店等触点。
- 企微活码：内部资料描述员工活码支持排班、渠道区分、客户添加统计及相关自动化配置；群活码用于多群承接。
- 活动小程序：承载活动介绍、报名、留资、签到/核销等活动环节（具体能力以当前版本核验）。
- 微信客服/智能名片/访客行为：补充不以加好友为前提的咨询或访问触点。
- 线索沉淀：将获客信息形成线索或客户相关记录，并支持后续分配与培育。

### 3.2 转化客户

- 线索分配、公海管理和跟进协同。
- 企微侧边栏展示客户画像、商机或相关业务信息，辅助销售在沟通场景中处理业务。
- 智能名片与素材雷达用于识别客户访问行为和兴趣信号。
- 企微内部协同支持跨员工、跨部门的客户跟进协作。
- 话术库、素材库和销售 SOP 用于统一销售沟通标准与跟进动作。

### 3.3 服务客户与持续经营

- 客户标签和画像支撑客户分层与生命周期运营。
- 客户群、一客一群、群 SOP 和群运营任务用于持续互动。
- 会话存档、质检和智能摘要用于沟通过程留痕与经验沉淀。
- 客户归属继承相关能力用于员工变动时降低客户关系断层风险。

## 4. 内部资料中出现的重点功能条目

以下是内部功能清单/产品介绍中的能力描述，不代表全部为当前默认开通或所有版本均可用：

|---|---|---|
| 员工活码 | 多员工二维码聚合，按排班/渠道等规则承接客户 | 企微接口限制、排班规则、标签与分配能力 |
| 群活码 | 多群承接与群满后的分流 | 群人数阈值、自动建群机制、二维码有效期规则 |

| 智能名片 | 展示企业/个人信息并记录访问行为 | 手机号授权模式、访问追踪范围和隐私告知 |
| 微信客服 | 多个微信生态入口接入客服 | 实际可接入入口、排班、机器人与侧边栏能力 |

## 5. 版本与功能清单的资料风险

内部摘要《销售易 SCRM 产品功能清单（简述）》存在以下结构性问题，不能直接作为当前正式功能清单或报价附件：

1. 文档称“全量功能清单共 7 大板块”，实际列出了 9 个编号板块。
2. 标题/概述中的功能项数量与表格条目不完全一致，部分分类可能存在合并或遗漏。
3. 将 V2608 同时写成最新功能基线和下一版本规划，版本状态存在冲突。
4. 摘要引用《产品定价单（产品功能清单）-20260930-V1.1》，但该正式定价单尚未取得，不能据摘要确认价格、License 或功能包含关系。
5. 文档中关于群活码人数阈值、群活码数量、标签额度、会话存档免费额度、PRM 用户限制等精确规则，均须以当前官方帮助中心、企微平台政策及正式报价资料核验。
6. Pitch Deck 2025 属历史内部介绍，适合用于理解能力全景和业务价值，不证明 2026 当前版本状态。

## 6. SCRM 与营销云、销售云、MA/CDP 的边界

- SCRM：聚焦企微生态客户连接、私域互动、线索运营、群运营、素材话术和会话协同。
- 营销云：公开产品定位覆盖线索获取、识别、培育、转化及分析；SCRM 是营销云/客户运营能力的重要组成，不宜把营销云等同于企微工具集合。
- 销售云：承接客户、线索、商机、销售过程和交易等核心销售管理流程。SCRM 中形成的互动行为和线索，应在适用配置下与销售业务衔接。
- MA：营销自动化旅程和触达编排。内部摘要中 V2608 同时出现 MA 节点增强，不应将 MA 功能无条件归为 SCRM。
- CDP/Data Cloud：客户数据整合、标签/画像和数据资产能力。具体数据平台产品边界与 SCRM 标签/画像功能需要按产品清单区分。
- 伙伴云/PRM：伙伴用户可能使用部分 SCRM 功能，但内部摘要明确列出若干权限限制；不能把伙伴用户权限等同于内部员工权限。

## 7. License、计费和合规提示

- 会话存档及相关智能能力可能依赖企业微信会话存档授权、销售易 License 或额外 AI 资源；具体组合和收费必须以正式报价/合同为准。
- 内部摘要曾描述智能话术推荐、智能标签、智能总结在特定时点限时限额免费；此为历史口径，不可作为当前商务承诺。
- 微信群发、客户群发、朋友圈等触达能力受微信/企业微信平台接口和频率规则约束；不可承诺无限量、无频控或绕过平台限制。
- 会话存档、客户画像、访问追踪和营销触达涉及个人信息处理，应确认企业授权、告知、数据使用目的、保存期限和访问权限。
- 多主体运营需核实不同主体间客户数据共享、管理员权限和数据隔离策略。

## 8. 售前场景设计建议

| 客户诉求 | 建议演示链路 | 关键指标 |
|---|---|---|
| 多渠道获客无法统一 | 活动/广告/活码入口 → 线索沉淀 → 查重分配 → 来源分析 | 有效线索率、线索响应时长、渠道转化率 |
| 企微客户数据沉淀不足 | 企微互动 → 客户标签/画像 → CRM 客户/线索关联 | 客户信息完整率、互动记录沉淀率 |
| 销售跟进不规范 | 素材/话术库 → 销售 SOP → 跟进记录 → 主管分析 | SOP 执行率、跟进及时率、转化率 |
| 社群运营低效 | 客户分群 → 群 SOP/群日历 → 执行反馈 → 群运营分析 | 群活跃度、任务执行率、活动转化率 |
| 客户沟通风险难追溯 | 会话存档 → 敏感词/事件监控 → 会话复盘 | 风险发现时效、质检覆盖率、问题闭环率 |
| 员工离职导致客户流失 | 离职继承 → 客户关系/业务数据交接 → 继承记录检查 | 客户关系交接率、客户流失率 |

演示时应选择客户真实痛点，不要一次性堆叠所有企微功能；突出“客户连接—数据沉淀—销售转化—持续运营”的闭环。

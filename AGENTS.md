# AGENTS.md — Neocrm Knowledge Base

## Purpose
This repository is the working, version-controlled mirror of the user's SalesEasy/Neocrm professional knowledge base. Use it as the primary source for product facts and solution design when working in this repository.

## Brand and naming
- Legal entity: 北京仁科互动网络有限公司.
- Chinese brand: 销售易.
- English brand: Neocrm.
- Do not use “SalesEasy” as the company, brand, or product name; it is an explicitly rejected incorrect name.

## Source-of-truth rules
1. Prefer the latest confirmed product material. Keep historical versions; do not silently overwrite or delete them.
2. Distinguish verified facts, inference, and items requiring validation.
3. Distinguish native product capability, configuration, extension/customization, third-party integration, and roadmap/planned capability.
4. Do not invent product features, customer cases, metrics, Skill counts, or delivery commitments.
5. Treat each customer project as independent. Do not transfer customer-specific facts between projects; reuse only generalized methods with provenance.
6. If sources conflict, surface the conflict and preserve provenance. Do not silently reconcile.
7. The governance index and product-specific fact-boundary documents define terminology and current status.

## Solution-design principles
Use the sequence: strategic alignment, architecture alignment, scenario-driven design, closed-loop delivery. Avoid generic feature pitching; connect business objectives, processes, data, AI/Agent/Skills, systems, and measurable outcomes.

- Standard Neocrm template core blue: #0052D9.

- For images generated from Markdown or presentation design documents, “演讲串联话术” is narrative-only context. Never render it as visible image text; preserve it in source documents.

## Repository maintenance
- Preserve the original Library files; this repository contains synchronized copies.
- Keep directory structure aligned with the Library knowledge taxonomy.
- Add new versions rather than replacing historical versions. Update the governance index when adding or superseding material.
- Before using a claim externally, check its source date and evidence status.

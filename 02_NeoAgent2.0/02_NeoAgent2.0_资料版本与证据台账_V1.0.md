## 3. 重要版本发现

本轮检索到白皮书增补稿的最高文件版本为 V5.15（2026-11-15 创建）。此前已发现 V5.14、V5.12、V5.10、V5.9、V5.6、V5.4、V5.3 等文件。它们属于同一白皮书的内容迭代版本，不是 NeoAgent 软件版本。

**版本命名必须区分：**
- NeoAgent 2.0：产品名称/产品体系代际。
- V5.15：白皮书文档修订号。
- 20260722：产品培训材料日期。
- 2026-04-16：官网产品文章页面标注日期。

不得将 V5.15 说成 NeoAgent 产品 V5.15，也不得因为它是最新草稿就把其中所有描述升级为已发布能力。

## 4. 需要纠正或谨慎使用的表达

| 表述 | 风险 | 推荐处理 |
|---|---|---|
| “200+ Skills” | 本轮未找到官方当前清单证明数量和范围 | 暂标待核验；对外不报数量 |
| “自主决策/自主执行所有业务” | 容易被理解为全自动、无人审核 | 限定在具体授权、工具、流程与人工确认范围内 |
| “杜绝 AI 幻觉” | 绝对化承诺 | 改为通过知识检索、权限、评测和审计降低错误风险 |
| “实时接入所有邮件/WhatsApp/ERP/MES” | 涉及连接器、接口、授权、部署与数据权限 | 按数据源逐项确认可用连接方式与同步时效 |
| “自动爬取海外工商/海关/制裁数据” | 依赖第三方数据源、许可和地区合规 | 标记外部数据集成/POC 场景 |
| “自动报价、审批、签约、派单” | 高风险写操作及客户承诺 | 必须核实操作工具、审批流、授权与二次确认 |
| “全球数据中心/满足所有国家合规” | 涉及部署合同与法务合规 | 以正式部署方案、数据处理协议、安全白皮书为准 |
| “多模态图纸识别、三维维修、离线知识库” | 白皮书草稿推演成分较高 | 作为规划/POC 假设，未验证前不得列入标准能力 |
| “NeoAgent 采用五层 Data for AI 架构” | 内部方案稿与官网公开四层架构不一致 | 对外主口径采用官网四层；五层稿仅作内部设计模型并明确来源 |

## 5. 下一步核验优先级

P0（优先取得）：
1. 当前正式 NeoAgent 2.0 产品手册/产品介绍。
2. 当前正式 Agent 与标准 Skills 清单、可用范围及 License。
3. NeoAgent 2.0 产品发布说明/版本变更记录。
4. 登录态帮助中心中 Agent、Skill、Data for AI、智能字段、智能流程、权限、日志与计费相关文档。

P1（第二批）：
1. Agent Builder / Prompt Builder / Action Builder 等平台功能操作说明。
2. 模型接入、Token 计费、运营监控和日志留存说明。
3. MCP、A2A、API、应用商城与 OAuth 授权支持范围。
4. Data Cloud 数据源、索引、权限继承和同步机制。

P2（方案验证）：
1. 汽车行业与制造业行业专属 Skills。
2. 海外市场情报、邮件/WhatsApp、招投标解析、渠道赋能、服务多模态等场景。
3. 跨区域经营分析、预测与跨系统写操作。
